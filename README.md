A one-line cat joke that reframes a familiar habit — knocking things off the table — as a deadpan science experiment: the cat isn't being spiteful, she's running gravity tests, and gravity keeps failing. The entry is a single self-contained line with no dependencies, so it reads the same on every run.

## Run it

```bash
python3 main.py
```

This prints the joke and writes it to `/output/entry.txt`.
